# Rapport mensuel des ventes d'un site e-commerce

**Contexte.** Une boutique en ligne a abandonné le high-tech pour l'alimentaire et les biens de consommation. La direction veut savoir si ce virage est réussi.

**Ma mission.** Construire les indicateurs de ventes dans Excel et les présenter dans un rapport mensuel court, orienté décision.

**Outils.** Excel (tableaux croisés, graphiques), PowerPoint.

## Ce que montre l'analyse (mars 2019 – février 2020)

- La transition d'offre est faite : l'alimentaire représente 73 % du chiffre d'affaires et le high-tech est arrêté.
- Le trafic a fortement augmenté, mais le **taux de conversion est passé de 10,2 % à 5,0 %** : le site attire beaucoup plus qu'il ne convertit.
- Le chiffre d'affaires recule de 6 % depuis le pic de décembre 2019.

## Recommandations

Simplifier le tunnel d'achat, relancer les visiteurs non convertis, et proposer des offres ciblées sur l'alimentaire, avec un objectif de 7,5 % de conversion à six mois.
